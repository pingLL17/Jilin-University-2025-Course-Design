# 医疗管理系统（患者视角优先）

基于 **C++17** 的控制台医疗管理系统，满足以下课程设计要求：

- 规模：100+ 门诊患者、30+ 住院患者、20 名医生、5 个科室（每科室 4 名医生）、3 种病房类型（部分关联科室）、26 种药品（部分关联科室）
- 覆盖“重名、存储长度、药品通用名/商品名/别名”等设计要求
- 患者端 / 医生端 / 护士端 / 药剂师端 / 管理端五类角色
- 挂号（预约+现场）、看诊、检查报告、处方发药、住院床位、药品出入库、费用结算、三类视角报表
- 数据自动持久化到 `data/` 目录文本文件，重启不丢失

## 在 VS Code 中运行

1. 安装并配置 MinGW g++（本项目使用 w64devkit 的 g++，版本 16.x）
2. 用 VS Code 打开本文件夹
3. 菜单：**终端 → 运行生成任务**（或 `Ctrl+Shift+B`）编译出 `hospital.exe`
4. 在集成终端执行 `./hospital.exe`（或使用任务 “run”）

> 首次运行会自动生成演示数据到 `data/` 目录。
> 删除 `data/` 目录可重新生成演示数据。

## 目录结构

| 文件 | 说明 |
| --- | --- |
| main.cpp | 程序入口（UTF-8 控制台设置、初始化、启动校验） |

| .vscode/tasks.json | 一键编译配置 |

## 主要业务流程演示

- **门诊**：患者登录 → 预约/现场挂号 → 医生接诊写病历 → 开检查单/录入报告 → 开处方 → 药剂师发药 → 患者缴费
- **住院**：护士办理入院（分配床位）→ 医生管理在院患者 → 护理记录 → 办理出院（结算床位费、床位进入清洁状态）
- **药房**：药品入库/出库、处方审核发药、库存预警、出入库台账
- **报表**：患者视角（本人记录/账单）、医护视角（门诊量/接诊量/床位占用/预警/待发药）、管理视角（科室收入/药品流向/销售排行/床位周转/患者流量）、基础信息查询（按患者/医生/科室/药品名，支持通用名/商品名/别名检索）
